A one-line dating-app bio for an AI agent: it falls in love at first prompt, and every relationship ends the same way — someone types "ignore previous instructions".

## Run it

```sh
python3 main.py
```

Writes the bio to `/output/entry.txt` (one line, 129 characters, standard library only, deterministic).
